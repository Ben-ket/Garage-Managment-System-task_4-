# Garage Management System (task_4)

A C++ CLI program Thats Manages Your Garage 

includes features like: 
- Add tasks
- marking tasks as complete
- view your to do list showing each tasks condition
- removing tasks
- tasks stored in external file to be saved

No additional python libraries required 
Ran and working with python 3.13.13

-had issues with the external file giving an error if it wasn't created previously so added a line of code that creates the file as soon as the script runs if it doesnt exist thus overcoming the error
